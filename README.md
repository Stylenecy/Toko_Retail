# 🚀 Toko Retail POS & Inventory Project

Welcome to the Capstone Project repository!

This repository contains the complete source code for a Point of Sale (POS) and Inventory Management application. The project is split into two main folders: **Backend** (API) and **Frontend** (Web App).

---

## 🖥️ Backend (`Toko_Retail/`)

The `Toko_Retail/` folder contains the entire API (server) that handles all business logic, database management, and authentication.

* **Tech Stack:** Node.js, Express, Sequelize
* **Database:** MySQL (via XAMPP)

➡️ **For complete installation and setup instructions, please read the [README inside the Toko_Retail folder](./Toko_Retail/README.md).**

---

## 🎨 Frontend (`pos-frontend/`)

The `pos-frontend/` folder contains the web application (User Interface) that cashiers or admins see and use. This application is built with React.

* **Tech Stack:** React, Vite, Tailwind CSS, Axios

➡️ **For complete installation and setup instructions, please read the [README inside the pos-frontend folder](./pos-frontend/README.md).**

---

## ⚙️ How to Run the Full Project

To run this application correctly, you must run **both** servers simultaneously:

1.  **Start the Backend Server:** Follow the instructions in `Toko_Retail/README.md` (will run on `http://localhost:3000`).
2.  **Start the Frontend Server:** Follow the instructions in `pos-frontend/README.md` (will run on `http://localhost:5173`).
